Para instalar cualquiera de estas skills en tu entorno cuando la necesites:
```bash
# Vía npx CLI
npx @rmyndharis/antigravity-skills install <nombre-de-la-skill>

# O mediante el comando de agente en el chat:
/skills-manager install <nombre-de-la-skill>
```
